# EV Market Analysis — Tableau

A portfolio project exploring electric-vehicle market patterns with a Tableau-ready sample dataset and dashboard documentation.

## Project contents
- `data/ev_market_data.csv` — synthetic sample EV market dataset
- `data/data_dictionary.csv` — field definitions and units
- `tableau/dashboard_plan.md` — recommended dashboard layout and interactions
- `tableau/calculated_fields.md` — suggested Tableau calculations
- `docs/project_report.md` — scope, methodology, limitations, and next steps

## Important data note
The dataset is synthetic demonstration data, not official market data. Do not cite it as real-world sales or market share.

## Tableau
Connect Tableau Desktop or Tableau Public to `data/ev_market_data.csv`, verify field types using the data dictionary, and build the views described in `tableau/dashboard_plan.md`.

The ZIP does not include a packaged Tableau workbook (`.twbx`).
